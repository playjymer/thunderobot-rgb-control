- 🖼️ **Синхронизация с Wallpaper Engine (Chroma SDK + Live Desktop)**:
  - Встроенный сервер **Razer Chroma REST API** (порт 12018) — принимает официальный поток LED-эффектов от плагина Wallpaper Engine.

## 🛠️ Архитектура и Управление железом

Программа напрямую взаимодействует с Embedded Controller (EC) ноутбука через библиотеку **Insyde DCHU API**:
- **Команда `103` (`0x67`)**: Управление 24-битным цветом `((Zone << 24) | (B << 16) | (R << 8) | G)`.
- **Команда `121` (`0x79`)**: Управление питанием и яркостью (0–255).
- **Команда `39` (`0x27`)**: Таймер автоотключения подсветки.

> **💡 Примечание по однозонным (1-Zone) клавиатурам:**
> Замененные клавиатуры для Clevo / Thunderobot часто распаяны в однозонную схему (все диоды на одной линии). Программа включает специальный режим `1-Zone`, где все градиенты, волны и эффекты рендерятся синхронно по всей клавиатуре с частотой 40–60 FPS.

## 🚀 Установка и Запуск

### Требования:
- **ОС**: Windows 10 / Windows 11 (64-bit)
- **Python**: 3.10 или новее
- Ноутбук на платформе **Thunderobot 911S / 911S Core / 911S Core D / Clevo**

### 1. Клонирование репозитория
```bash
git clone https://github.com/your-username/thunderobot-rgb-control.git
cd thunderobot-rgb-control
```

### 2. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 3. Запуск
```bash
# Запуск интерфейса
python main.py

# Либо через пакетный файл:
Launch_Thunderobot_RGB.bat
```

| Сочетание / Действие | Функция |
| :--- | :--- |
| **`Fn + / (Numpad)`** | Мгновенно открыть / развернуть панель управления RGB |
